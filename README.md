# Sparse identification of the Rayleigh–Plesset equation from spark-generated cavitation bubbles

AE498 Project 1, Chenghao Xu, University of Illinois Urbana-Champaign.

This folder contains the code and processed data needed to reproduce all results and figures of the report. The method is sparse regression (SINDy / PDE-FIND approach) applied to the measured first-cycle radius R(t) of 19 spark-generated cavitation bubbles.

## How to run

Requires Python 3.9 or newer with NumPy, SciPy, Matplotlib and openpyxl. If they are not
installed yet:

```bash
python -m pip install -r requirements.txt
```

Then run:

```bash
python rp_sindy_radius_final.py        # prints all numbers in Section IV of the report (a few seconds)
python make_figures_final.py           # writes fig_radius.pdf (Fig. 1) and fig_results.pdf (Fig. 2)
```

## Data

The folder `Radius/` contains the processed radius data used in the report: one Excel file per experiment, `Radius/single_bubble_start_<n>_radius_new.xlsx` (19 files, 320 kB; experiment numbers 1–17, 19 and 20). Each row is one frame of the first expansion–collapse cycle. The relevant columns are (the code reads `t_us`, `R_px` and `ok`):

| Column | Meaning |
|---|---|
| `frame` | frame number in the recording |
| `t_us` | time since the spark, in microseconds (frame interval 14.815 µs) |
| `R_px` | bubble radius, in pixels |
| `ok` | quality flag: 1 = usable frame, 0 = frame that could not be measured |

The other columns (bubble centre, area-equivalent radius, fit quality) are not used.

How the data were obtained:

- Each bubble was generated by a spark discharge in water and recorded with a Photron FASTCAM Mini AX200 high-speed camera at 67 500 frames per second, 256 × 256 pixels, 8 bit.
- The radius was extracted frame by frame with a Python edge-detection script. Frames in which the edge could not be detected automatically (mainly early frames saturated by the light of the spark) were measured manually in Fiji (ImageJ) with a resolution of 0.5 px.
- Pixels are converted to millimetres in the code with 19.23 px/mm, obtained from an image of a ruler.

The raw high-speed videos (439 MB) and the extraction script are not included in this folder. They are available from the author on request.
